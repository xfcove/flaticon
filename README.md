# Flaticon CDN Icon Gallery

A blazing-fast VS Code sidebar extension that gives you an endless, searchable gallery of high-quality icons right inside your editor. Find the perfect icon and copy its CDN link with a single click.

## 🚀 Features

- **Instant Search & Preview:** Search through thousands of icons (powered by Iconify) directly in your VS Code sidebar.
- **1-Click Copy:** Click on any icon box to instantly copy its direct CDN SVG link to your clipboard.
- **Massive Brand Gallery:** Start up instantly with a grid of top developer brand icons (React, Node, Python, Docker, etc.).
- **Dark-Theme Optimized:** Icons are displayed on clean, bright backgrounds to ensure perfect visibility regardless of your VS Code theme.
- **Pagination:** Seamlessly browse through hundreds of icons with built-in page controls.

## 🛠️ Usage

1. Click the **Flaticon** icon in the left Activity Bar.
2. Type a keyword (e.g., `user`, `settings`, `arrow`) in the search box.
3. Click any icon to copy its `https://api.iconify.design/...` link.
4. Paste it directly into your HTML `<img>` tags or React/Next.js components.

## ⚙️ Requirements

- VS Code 1.80.0 or higher.
- Active internet connection to fetch the CDN gallery.
